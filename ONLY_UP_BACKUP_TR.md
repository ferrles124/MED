# Only Up Skybound v17 Yedeği

Bu klasör, Only Up Skybound oyununun çalışan v17 sürümünün GitHub yedeğidir.

## Proje

- Godot Web export için hazırlanmış proje
- Bölüm 1 ve Bölüm 2
- 67 GLB kaynak asset
- Baked mesh collision prefabları
- Tam mesh collision kullanan büyük araçlar
- Checkpoint ve respawn sistemi
- 1. şahıs / 3. şahıs kamera geçişi
- Özgün ses efektleri ve seçilen arka plan müziği

## Açma

Godot Project Manager üzerinden `only_up_skybound_v17/project.godot` dosyasını import edin.

`.godot` önbelleği yedeğe dahil edilmemiştir; Godot projeyi açarken yeniden oluşturacaktır.
